# Imagens dos mapas

A seção "Análise por mapa" mostra uma imagem por mapa. O arquivo precisa ter **exatamente** o nome do mapa em minúsculas:

| Arquivo | Mapa | Situação |
|---|---|---|
| `ascent.webp` | Ascent | incluído |
| `lotus.webp` | Lotus | incluído |
| `haven.webp` | Haven | incluído |
| `split.webp` | Split | incluído |
| `abyss.webp` | Abyss | incluído |
| `sunset.*` | Sunset | falta |
| `summit.*` | Summit | falta |
| `breeze.*` | Breeze | falta |
| `pearl.*` | Pearl | falta |
| `fracture.*` | Fracture | falta |

As cinco imagens incluídas vieram do protótipo do time (`otimizacao-de-front-end-e.zip`), convertidas de PNG para WebP (de ~2 MB para ~170 KB cada). São ilustrações temáticas de cada mapa, não capturas oficiais do jogo.

Extensões aceitas: `.jpg`, `.jpeg`, `.png`, `.webp`. Enquanto um arquivo não existe, o card mostra "Imagem do mapa não disponível no projeto", e não a imagem de outro mapa. Depois de adicionar um arquivo, rode o front de novo.
